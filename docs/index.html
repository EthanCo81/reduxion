Reduxion

A number puzzle brain teaser

About

Reduxion is an addictive number puzzle game that challenges you to reach a target number using basic math operations. Split, add, subtract, and multiply your way to victory across three difficulty levels.

How to Play

  • You're given a set of numbers and a target number.
  • Tap one or two number tiles to select them.
  • Split — Select one even number (greater than 2) to divide it into two equal halves.
  • Add, Subtract, Multiply — Select two numbers, then tap an operation to combine them.
  • Match any number on the board to the target to win!
  • Try to solve it in as few moves as possible.
